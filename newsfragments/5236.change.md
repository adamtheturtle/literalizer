C now raises `UnrepresentableInputError` for native record-array reassignment instead of generating invalid C code.

C#, D, Dart, F#, Groovy, Julia, Mojo, Nim, Odin, PHP, Python, Raku, SystemVerilog, and Zig now give colliding dotted-call helper types distinct names so calls such as `a.foo.Foo.bar` compile and pass static checks.
