# 2026.11.04.1 (2026-11-04)

## Changes

- C# collection inference now uses `object` for known non-null heterogeneous elements and `object?` for values that can be null.
  Empty collection defaults and custom fallback types are preserved.
  Generated arrays, maps, sets, and record map fields compose with non-null consumer types without extra compiler warnings.
  ([#6696](https://github.com/adamtheturtle/literalizer/issues/6696))
- Java's native datetime formats now normalize fractional UTC offsets to the equivalent UTC instant instead of generating code that fails at runtime.
