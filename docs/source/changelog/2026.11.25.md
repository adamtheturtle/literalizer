# 2026.11.25 (2026-11-25)

## Changes

- Use equivalent generic Swift array annotations for deep singleton chains to avoid excessive compiler work while preserving their exact types and values.
  ([#5264](https://github.com/adamtheturtle/literalizer/issues/5264))
- Fix C++14 carrier construction for nested maps whose value types widen across sibling maps.
  ([#6919](https://github.com/adamtheturtle/literalizer/issues/6919))
- Make Roc V1 the default and only target, pinned to compiler nightly `2026-11-15-f25da45` and `basic-cli 0.28.1`.
  Remove the V0 target and command call style; `Roc()` now emits the new compiler's syntax and calls use `Roc.call_styles.POSITIONAL`.
  Users retaining the legacy compiler and platform must keep an older Literalizer release.
  Validate literals, references and calls with the complete JSON round-trip input and an executable recursive inspection regression.
  ([#6984](https://github.com/adamtheturtle/literalizer/issues/6984))
- Reject empty mappings and numeric string mapping keys when constructing PHP arrays in function-call arguments, including ordered mappings and keys with reference values.
  ([#6986](https://github.com/adamtheturtle/literalizer/issues/6986))
- Reject empty mappings and null or NaN table keys when constructing Lua function-call arguments, including nested tables, ordered mappings and keys with reference values.
  ([#6987](https://github.com/adamtheturtle/literalizer/issues/6987))
- Rendering recursion errors now propagate as `RecursionError` instead of being reported as input parse errors.
  ([#7110](https://github.com/adamtheturtle/literalizer/issues/7110))
- PureScript now accepts a `module_name` option for wrapped literals and calls.
  ([#7170](https://github.com/adamtheturtle/literalizer/issues/7170))
- Replace calls to `literalize_native_calls` with `literalize_invocations`.
  The same arguments and bare native recipes remain supported.
  ([#7185](https://github.com/adamtheturtle/literalizer/issues/7185))
- Go RECORD calls now pass direct record arguments as structs with their generated types.
  ([#7226](https://github.com/adamtheturtle/literalizer/issues/7226))
- Go now widens populated maps with mixed values to an interface when the configured default value type cannot hold them.
  ([#7227](https://github.com/adamtheturtle/literalizer/issues/7227))
- Go RECORD calls now reject a record list beside an incompatible empty sibling before generating code.
  ([#7228](https://github.com/adamtheturtle/literalizer/issues/7228))
- COBOL wrappers accept a `program_name` option.
  Generated call wrappers keep their program identifier distinct from nested call stubs.
- Elm output accepts `null_constructor_name`.
  Use it to customize the constructor for null values.
- Jsonnet output now supports `NewVariable` declarations.
  Wrapped files declare a local binding and evaluate to its value.
- Normalize fractional UTC offsets to the equivalent UTC instant in native PHP and Swift datetimes, and reject normalization outside the supported year range.
  Reject sub-minute UTC offsets in native TOML and YAML timestamps instead of emitting invalid documents.
- YAML output supports `NewVariable` and `ExistingVariable` as named root entries.
  Names resembling boolean or null values stay string keys.
