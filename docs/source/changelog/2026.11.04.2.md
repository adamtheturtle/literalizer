# 2026.11.04.2 (2026-11-04)

## Changes

- Add explicitly typed native Objective-C invocations, constructors, nested wrappers, and result bindings, including declarative data/companion recipes and real-class executable golden fixtures. ([#6698](https://github.com/adamtheturtle/literalizer/issues/6698))
- Clarify call-reference preservation, Rust's conservative cloning of unknown references, and how `ref_values`, `bound_refs`, and `consumable_refs` affect ownership.
  ([#6700](https://github.com/adamtheturtle/literalizer/issues/6700))
- Avoid unused mapping imports in eagerly evaluated Python 3.8 record annotations beside empty sequences.
- Dart's native datetime format now preserves UTC offsets containing seconds or microseconds using exact duration arithmetic.
- Give Scala arrays containing empty and populated record-array siblings a concrete outer element type.
- Give ragged C++ array arguments an explicit carrier type and its required headers so wrapped calls compile.
- Match Crystal record fields containing records to their configured tuple sequence representation.
- Match Swift record fields containing records to their configured tuple sequence representation.
- Scala's native datetime format now normalizes fractional UTC offsets to the equivalent UTC instant instead of generating code that fails at runtime.
- YAML parsing now uses private signed-zero constructors, avoiding recursion failures after repeated thread lifetimes.
