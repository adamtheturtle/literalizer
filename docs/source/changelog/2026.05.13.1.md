# 2026.05.13.1

- `~literalizer._language.LanguageCls` now exposes `supports_empty_dict_key`, `supports_call_style`, `supports_default_dict_key_type`, `supports_default_dict_value_type`, `supports_default_sequence_element_type`, `supports_default_set_element_type`, and `supports_default_ordered_map_value_type` flags alongside the existing `supports_module_name`.
