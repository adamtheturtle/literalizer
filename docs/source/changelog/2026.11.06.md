# 2026.11.06 (2026-11-06)

## Changes

- Add `describe_callable` to render short callable descriptions from structured metadata, including validated native selectors and explicit language overrides, without sample values.
  ([#6803](https://github.com/adamtheturtle/literalizer/issues/6803))
- Allow `describe_callable` to reuse caller-supplied naming functions for default method and parameter names while preserving explicit language overrides.
  ([#6805](https://github.com/adamtheturtle/literalizer/issues/6805))
- Reuse the runtime-checked C++14 variant visitor across renders instead of rebuilding its `@beartype` wrapper on every traversal.
