# 2026.04.24

- `literalize_call` with `per_element=True` now widens Rust's `TAGGED_ENUM` scalar wrapping across sibling calls at matching argument slots.
  Previously the wrap analysis ran per call, so a locally-homogeneous sibling dict would emit unwrapped scalars even when another call at the same slot was heterogeneous.
  A second `m.process(HashMap::from([("a", "x")]))` would not match the `&HashMap<&'static str, Value>` parameter implied by the first heterogeneous call.
  Mirrors the dict-opener widening already applied for typed dict languages on the per-element call path.

- Erlang output for negative infinity now uses the quoted atom `'-inf'` instead of bare `-inf`, avoiding a guaranteed runtime `badarith` error.
